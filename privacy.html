개인정보처리방침

시행일: 2026년 10월 27일 · 운영자: Minseok Ko

이 방침은 RoutineMaster Windows 앱과 이 안내 웹사이트에 적용됩니다. 문의는 omicron9ms@gmail.com으로 보내주세요.

1. 접근하고 저장하는 정보

앱은 사용자가 입력한 루틴 설정, 할 일, 연결된 프로그램·폴더·웹사이트 정보와 진행·완료 기록을 사용자의 PC에 저장합니다. Anki 기능을 설정하면 로컬 AnkiConnect에서 덱 정보와 학습 잔여량을 조회합니다.

Google Tasks 연결을 선택하면 OAuth 인증 토큰, OAuth 클라이언트 설정, 연결 목록 및 할 일의 ID, 제목, 날짜, 완료 상태, 정렬·수정·삭제 관련 동기화 정보를 처리합니다. 연결 및 복구에 필요한 Google Tasks 목록의 이름과 ID도 조회할 수 있습니다. Google 계정 비밀번호는 수집하거나 저장하지 않습니다.

2. Google 데이터 사용 목적

Google Tasks 데이터는 연결한 목록의 할 일을 표시하고 생성·수정·완료·삭제·정렬하며, 로컬 변경과 Google의 변경을 동기화하고 중복 생성이나 연결 오류를 복구하기 위해 사용합니다. 요청하는 OAuth 권한은 https://www.googleapis.com/auth/tasks입니다.

Google에서 받은 데이터를 판매하거나 광고, 신용 평가 또는 범용 AI·머신러닝 모델 학습에 사용하지 않습니다. 운영자는 사용자의 PC에 저장된 데이터나 Google Tasks 데이터에 자동으로 접근하는 관리 기능을 제공하지 않습니다.

3. 저장 위치와 보호

앱 데이터는 기본적으로 %LOCALAPPDATA%\RoutineMaster에 저장됩니다. OAuth 토큰과 가져온 클라이언트 설정은 Windows의 현재 사용자에 연결된 암호화 기능으로 보호됩니다. 할 일·루틴·진행 기록과 백업은 로컬 JSON 파일로 저장되며 동일한 토큰 암호화가 적용되는 것은 아닙니다. 사용자는 PC 계정과 백업의 접근 권한을 관리해야 합니다.

Google 인증과 동기화는 Google 서비스와의 HTTPS 통신을 사용합니다. 이 앱은 루틴·할 일·인증 토큰을 저장하는 별도의 운영자 서버를 사용하지 않습니다.

4. 외부 서비스와 정보 공유

Google 연결을 사용하면 동기화에 필요한 할 일 정보가 사용자의 Google 계정으로 전송되고 Google의 정책에 따라 처리됩니다. 앱에서 프로그램·폴더·웹 연결을 위해 저장한 실행 대상 정보는 Google Tasks 동기화 데이터에 포함하지 않습니다. 사용자가 외부 웹사이트를 열거나 문의 이메일을 보내면 해당 서비스가 관련 정보를 처리합니다.

이 안내 사이트는 GitHub Pages에서 제공되며 별도의 로그인, 광고, 분석 스크립트 또는 자체 쿠키를 사용하지 않습니다. 호스팅 제공자인 GitHub는 사이트 제공과 보안을 위해 IP 주소 등 접속 정보를 처리할 수 있습니다. 자세한 사항은 GitHub 개인정보처리방침과 Google 개인정보처리방침을 확인하세요.

5. 보관, 권한 철회 및 삭제

로컬 데이터와 백업은 사용자가 삭제할 때까지 PC에 남을 수 있습니다. 지난날 완료 기록은 Google 항목을 수정하거나 삭제한 뒤에도 로컬 기록에 남을 수 있습니다.

  1. Google 접근을 중단하려면 Google 계정의 외부 앱 연결 관리에서 해당 OAuth 앱의 접근 권한을 삭제하세요.
  2. 로컬 인증 정보를 지우려면 앱을 완전히 종료한 뒤 위 데이터 폴더의 google-auth.dat와 남아 있는 인증 파일 사본을 삭제하세요. 다운로드했던 원본 OAuth JSON도 필요에 따라 별도로 삭제하세요.
  3. 로컬 기록을 모두 지우려면 앱 종료 후 %LOCALAPPDATA%\RoutineMaster 폴더와 별도로 만든 백업을 삭제하세요. 이 작업은 Google 정보뿐 아니라 루틴 설정과 다른 앱 기록도 삭제합니다.
  4. Google에 저장된 목록과 할 일은 권한 철회나 로컬 파일 삭제만으로 삭제되지 않습니다. Google Tasks에서 별도로 삭제할 수 있습니다.

문의 메일에 개인정보를 포함해 보낸 경우, 해당 메일의 삭제 요청도 위 연락처로 보낼 수 있습니다.

6. Google API 정책 준수

RoutineMaster의 Google API를 통해 받은 정보의 사용 및 다른 앱으로의 전송은 Limited Use 요구 사항을 포함한 Google API Services User Data Policy를 따릅니다.

7. 변경과 문의

앱의 데이터 처리 방식이 바뀌면 이 페이지와 시행일을 갱신합니다. 문의: Minseok Ko · omicron9ms@gmail.com

English summary

RoutineMaster is a personal Windows app. It processes Google Tasks lists and task data only for task synchronization and recovery after user authorization. Tokens are encrypted for the current Windows user; task data and backups are stored locally as JSON. There is no separate developer-operated data server. Google user data is not sold or used for advertising or training generalized AI models. Users can revoke access in their Google Account and delete local files and Google Tasks data separately.
